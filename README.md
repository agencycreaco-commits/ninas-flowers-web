# Nina's Flowers · web

Catálogo de ramos con pedidos por WhatsApp, página de Eventos y formulario «Diseña tu evento».

- `npm install` · `npm run dev` para trabajar en local.
- `npm run build` genera `dist/` (HTML estático por página) para Cloudflare Pages.
- Manual para el día a día: [MANUAL.md](MANUAL.md).
